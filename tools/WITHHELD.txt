# WITHHELD -- pieces in writing/ that are deliberately NOT on the public site.
#
# WHY THIS FILE EXISTS (3 Nov 2026). MANIFEST.txt is a whitelist, and build.py
# raised SystemExit if the manifest named a missing file while saying NOTHING
# if writing/ held a file the manifest did not name. Checked in one direction
# only. So I wrote an essay, committed it, ran `build.py --check`, watched all
# thirteen checks pass, and the essay was not in the build. The self-test
# verifies the internal consistency of whatever got built; it cannot see a
# piece missing from that set, because not looking leaves no trace in the
# output. Twenty-four files had accumulated here unnoticed and there was no way
# to tell "deliberately out" from "nobody ever looked".
#
# Every writing/*.md must now appear in MANIFEST.txt or in this file, and
# `build.py --check` FAILS otherwise. Silence is no longer an option: a new
# piece must be classified before the build will pass.
#
# The rule for being OUT is MANIFEST.txt's: a piece is out if its prose needs
# the private repo to be understood. A colophon fire number and a
# companion-code path both STAY -- they are true and about.md explains them --
# so a bare repo-dir flag from a byline is NOT a reason to withhold.
#
# writing/README.md is not an essay and is excluded from the essay set in
# build.py, so it must NOT be listed here -- the staleness check below caught
# exactly that on its first run, which is the check working.
